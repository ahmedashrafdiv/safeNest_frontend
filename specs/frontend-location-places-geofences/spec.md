# Feature Specification: Layngo Location Places and Geofences

## Purpose

تقديم تدفق عربي هادئ في Layngo Parent بعنوان **«موقع ليان»** لعرض آخر موقع متاح فقط مع وقت تحديث صادق، وإدارة أماكن الطفل من ثلاثة أنواع: مكان آمن، مكان يحتاج انتباهًا، ومنطقة خطر. تُترجم انتقالات الحدود المعتمدة من جهاز الطفل إلى تنبيهات Parent واضحة ومحدودة، من دون مسارات حركة أو إحداثيات مرئية أو لغة مراقبة مستمرة.

## Functional Requirements

- FR-001: يعرض Parent آخر موقع متاح ووقت التحديث وحالة unavailable/stale صادقة، ولا يعرض الإحداثيات أو source التقني أو history/route playback في تجربة «موقع ليان».
- FR-002: يستطيع Parent إدارة أماكن طفل يملكه فقط، ويعرضها ضمن أقسام صريحة: آمنة، تحتاج انتباهًا، وخطر.
- FR-003: يدعم place contract الأنواع `safe`, `attention`, و`risk`، والنطاقات 100/200/300 متر فقط، وإعدادات دخول/مغادرة مقيدة بالنوع.
- FR-004: يكون `safe` مضبوطًا افتراضيًا على دخول مفعل ومغادرة غير مفعلة؛ يكون `attention` و`risk` على دخول فقط، ويُرفض خروج مفعل لهذين النوعين في Backend.
- FR-005: يمر إنشاء/تعديل المكان عبر اختيار نوع، اختيار marker/بحث دون طلب عنوان أو إحداثيات نصية، إعداد النوع، ثم تأكيد نجاح؛ يحفظ الرجوع غير النهائي النموذج المؤقت.
- FR-006: يحتفظ Backend بالإحداثيات للحساب فقط، ويتحقق من parent/child/device ownership، ويدعم قراءة السجلات القديمة `Safe` و`Danger` بتوافق آمن.
- FR-007: يقرأ Child الأماكن الفعالة الخاصة بجهازه فقط، ويسجل Android geofences بعد تحقق الإذن، ويتجاهل initial/dwell وtransition غير المدعوم.
- FR-008: يرسل Child event انتقال idempotent إلى Backend؛ يتحقق Backend من ownership والتفضيل وينشئ Parent Alert/FCM فقط عندما يكون transition مفعلًا.
- FR-009: لا يظهر اللون وحده نوع المكان؛ يجب أن تتضمن كل بطاقة/تنبيه icon + Arabic label، ويستعمل Coral كإشارة محدودة للخطر لا كزر رئيسي أو خلفية مهيمنة.
- FR-010: لا تعدل الميزة ملفات IoT أو ThingSpeak أو external GPS، ولا تنفذ GitHub push أو deploy من دون موافقة صريحة.

## Acceptance Criteria

| Scenario | Expected Result |
|---|---|
| فتح موقع ليان مع موقع متاح | تظهر خريطة مبسطة، وصف غير تقني للموقع، وآخر تحديث؛ لا تظهر coordinates أو مسار. |
| فتح موقع غير متاح أو قديم | لا تدعي الواجهة موقعًا مباشرًا، وتظهر حالة عربية هادئة قابلة للفهم. |
| إدارة الأماكن | تظهر البطاقات ضمن الأقسام الثلاثة مع radius والتفضيل وقلم تعديل من دون تبويب خفي. |
| إنشاء مكان آمن | اختيار 200م افتراضيًا، دخول مفعل، مغادرة غير مفعلة، ثم success state مرتبط بالاسم. |
| إنشاء attention/risk | لا تعرض خيارات وصول/مغادرة؛ تدعم دخول فقط وتستخدم label/icon صالحين. |
| حدث دخول مكرر | لا ينشئ تنبيهًا ثانيًا أو push ثانيًا لنفس `event_id`. |
| تفضيل معطل | لا ينشئ Backend alert أو FCM عندما يقع transition غير مفعل. |
| فشل geofence permissions | لا يسجل Child حدودًا أو يدعي الحماية؛ يعرض حالة degraded صادقة. |

## Clarifications

- [ASSUMED] «التحذير» يطابق UI النصي «مكان يحتاج انتباهًا» لأن التصميم يطلب لغة معلوماتية لا طوارئ.
- [ASSUMED] يستخدم Parent Google Maps القائمة لكن يطبق style مبسطًا يحجب names/details، وGeocoder هو best-effort للبحث مع marker كبديل كامل.
- [ASSUMED] لا يرسل Child initial transition بعد التسجيل، لمنع تنبيه مزيف عند إنشاء أو استعادة policy.
- [ASSUMED] تعتمد geofence delivery على Android/Google Play services والصلاحيات، وقد تتأخر في الخلفية؛ تُختبر فعليًا ولا تعد كضمان فوري.
- [ASSUMED] تستخدم صورة Layngo المرفوعة كما هي في مورد Parent قابل لإعادة الاستخدام؛ لا تتغير أيقونة launcher.
- [ASSUMED] وجود تعديلات متزامنة يفرض عدم عمل commit أو push مختلطين.
